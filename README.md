# Obsi Sync

Плагин Obsidian для сервера obsi-mcp: синхронизирует файлы между устройствами со сквозным шифрованием rclone, публикует разрешённые заметки в AI Available и применяет ожидающие правки от MCP-клиентов.

**Полное руководство:** [docs/PLUGIN.md](docs/PLUGIN.md). В нём описаны первый вход, все разделы настроек, подключения vault'ов, правила доступа ИИ, администрирование, отладка и решение типовых проблем.

## Быстрый старт

```bash
npm install
npm run build
```

Скопируйте `main.js`, `manifest.json` и `styles.css` в `<vault>/.obsidian/plugins/obsi-sync/` и включите плагин в Obsidian. При обновлении сохраняйте `data.json`: в нём хранятся локальные настройки и секреты.

На первом запуске откроется пошаговый мастер: «У меня есть приглашение» (вставьте сообщение от администратора целиком, мастер сам найдёт адрес сервера и код), «Войти в мой аккаунт» или подключение по токену; затем серверный vault (новому аккаунту мастер сразу предлагает создать первый), отдельный пароль шифрования и доступ ИИ. В конце мастер сам запускает первую синхронизацию. AI Available выключен по умолчанию; выбранные для него файлы передаются серверу открытым текстом.

Настройки разделены на вкладки «Обзор» (состояние, синк и пауза одной кнопкой), «Синхронизация», «Папки», «Устройства», «ИИ» и «Сервер». Состояние видно и в строке статуса, по щелчку открывается меню быстрых действий.

Администратор приглашает людей в настройках Obsi Sync → «Сервер» → «Люди» (нужен admin-токен): плагин выдаёт готовое к пересылке сообщение с адресом сервера и кодом. Вошедший в аккаунт пользователь добавляет устройства на вкладке «Устройства» (у каждого свой QR-код и своя кнопка «Отключить») и подключает Claude и другие MCP-клиенты на вкладке «ИИ» → «Ассистенты» с готовыми командами для копирования.

Чтобы перенести готовые подключения на другое устройство, откройте вкладку «Устройства» и создайте QR-код. Передайте набор приватно: он содержит действующий токен устройства и пароли подключений. В мастере нового устройства выберите «Перенести настройку с другого устройства», снимите QR камерой, выберите изображение QR-кода или вставьте текст. Импорт заменяет адрес сервера, токен и список подключений; на ненастроенном устройстве сразу запускается первая синхронизация, а если устройство уже было настроено, её нужно запустить вручную после проверки.
