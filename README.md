# Obsi Sync

Плагин Obsidian для сервера obsi-mcp: синхронизирует файлы между устройствами со сквозным шифрованием rclone, публикует разрешённые заметки в AI Available и применяет ожидающие правки от MCP-клиентов.

**Полное руководство:** [docs/PLUGIN.md](docs/PLUGIN.md). В нём описаны первый вход, все разделы настроек, подключения vault'ов, правила доступа ИИ, администрирование, отладка и решение типовых проблем.

## Быстрый старт

```bash
npm install
npm run build
```

Скопируйте `main.js`, `manifest.json` и `styles.css` в `<vault>/.obsidian/plugins/obsi-sync/` и включите плагин в Obsidian. При обновлении сохраняйте `data.json`: в нём хранятся локальные настройки и секреты.

На первом запуске укажите адрес сервера и токен устройства (`kind=device`, права `read`/`write`). Затем выберите серверный vault и решите, подключать ли весь локальный vault. Для синхронизации нужен пароль, одинаковый на устройствах одного серверного vault. AI Available выключен по умолчанию; выбранные для него файлы передаются серверу открытым текстом.

Чтобы перенести готовые подключения на другое устройство, откройте верхнюю вкладку «Добавить другое устройство»: текст device-adder и QR появятся автоматически. Передайте набор приватно: он содержит действующий токен устройства и пароли подключений. На экране приветствия нового устройства выберите «Добавить с другого устройства», вставьте текст, выберите изображение QR-кода или снимите его камерой. Импорт после подтверждения заменяет адрес сервера, токен и список подключений; синхронизацию нужно запустить вручную.
