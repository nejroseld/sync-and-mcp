# Obsi Sync

Плагин Obsidian для сервера obsi-mcp: синхронизирует файлы между устройствами со сквозным шифрованием rclone, публикует разрешённые заметки в AI Available и применяет ожидающие правки от MCP-клиентов.

**Полное руководство:** [docs/PLUGIN.md](docs/PLUGIN.md). В нём описаны первый вход, все разделы настроек, подключения vault'ов, правила доступа ИИ, администрирование, отладка и решение типовых проблем.

## Быстрый старт

```bash
npm install
npm run build
```

Скопируйте `main.js`, `manifest.json` и `styles.css` в `<vault>/.obsidian/plugins/obsi-sync/` и включите плагин в Obsidian. При обновлении сохраняйте `data.json`: в нём хранятся локальные настройки и секреты.

На первом запуске откроется пошаговый мастер: адрес сервера и вход по учетной записи (логин/пароль), access-токен или device-токен, серверный vault, отдельный пароль шифрования и доступ ИИ. Новую учетную запись создают по приглашению администратора; пользователь может создать собственный vault. В конце мастер сам запускает первую синхронизацию. AI Available выключен по умолчанию; выбранные для него файлы передаются серверу открытым текстом.

Настройки разделены на вкладки «Обзор» (состояние, синк и пауза одной кнопкой), «Синхронизация», «Папки», «Устройства», «ИИ» и «Сервер». Состояние видно и в строке статуса, по щелчку открывается меню быстрых действий.

Администратор сервера найдёт зарегистрированных пользователей и создаст приглашения в настройках Obsi Sync → «Сервер» → «Учётные записи». Для управления требуется admin-токен. Обычные пользователи входят по имени пользователя и паролю; токены доступа остаются отдельным способом подключения для устройств и клиентов.

Чтобы перенести готовые подключения на другое устройство, откройте вкладку «Устройства» и нажмите «Показать QR-код». Передайте набор приватно: он содержит действующий токен устройства и пароли подключений. В мастере нового устройства выберите «Перенести настройку с другого устройства», снимите QR камерой, выберите изображение QR-кода или вставьте текст. Импорт заменяет адрес сервера, токен и список подключений; на ненастроенном устройстве сразу запускается первая синхронизация, а если устройство уже было настроено, её нужно запустить вручную после проверки.
