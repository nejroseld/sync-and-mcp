# Архитектура плагина Obsi Sync

Плагин Obsidian синхронизирует несколько vault'ов с сервером, шифруя имена и содержимое файлов на устройстве. Отдельно он публикует разрешённые правилами заметки в AI Available и применяет правки из очереди MCP.

`src/main.ts` запускает интеграцию с Obsidian. `src/settings.ts` хранит настройки и mount'ы, `src/ui/` содержит настройку подключения. `src/sync/` выполняет E2EE-синхронизацию; части движка, заимствованные из Remotely Save под Apache-2.0, перечислены в `NOTICE`. `src/ai/` вычисляет разрешённые файлы, публикует их и применяет правки. `src/api/` реализует HTTP-клиент к серверу.

Общий контракт HTTP и MCP зафиксирован в [API.md](API.md). Сервер находится в отдельном репозитории. Для сквозного теста можно указать путь к его checkout через `OBSI_SERVER_DIR`; по умолчанию ожидается соседний каталог `../server`.

Пароли шифрования и токены сохраняются только в настройках устройства. Плагин исключает свой `data.json` из синхронизации. Данные AI Available передаются серверу открытым текстом только по правилам из `.obsi/ai-rules.json` и только если публикация включена.
