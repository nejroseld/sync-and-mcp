# Карта кода плагина

- `src/main.ts`, `src/settings.ts`, `src/syncManager.ts` — интеграция с Obsidian, настройки и запуск синхронизации.
- `src/ui/` — окно первого подключения, вкладки настроек и скрытый раздел Dev. `src/ui/kit.ts` — общие компоненты интерфейса (карточки, выбор-карточки, плашки, поля, подтверждения, относительное время); `src/ui/settingsTab.ts` — оболочка вкладок, сами вкладки лежат в `src/ui/settings/` (`overview`, `sync`, `folders`, `devices`, `ai`, `server`, `dev`, общий контекст в `context.ts`); `src/ui/statusBar.ts` — строка статуса и единое вычисление состояния синка.
- `src/ui/setupModal.ts`, `src/onboarding.ts` — пошаговый мастер первого входа и его проверяемые хелперы (нормализация адреса, разбор ошибок подключения, проверка пароля по данным vault).
- `src/deviceAdder.ts`, `src/deviceName.ts`, `src/ui/qrTransfer.ts` — проверка набора для переноса подключения, случайное имя устройства и имя по системе/модели, локальное создание/чтение QR.
- `src/ui/mcpPreview.ts` — окно «Что написал ИИ»: один запрос очереди MCP без фонового опроса.
- `src/i18n.ts`, `src/locales/ru.ts` — выбор языка Obsidian и переводы интерфейса.
- `src/api/` — HTTP-клиент и типы контракта из [API.md](API.md).
- `src/sync/` — шифрование, mount'ы, локальная и серверная файловые системы, алгоритм синхронизации.
- `src/ai/` — правила доступа, публикация разрешённых файлов и применение правок MCP.
- `tests/` — модульные тесты; `tests-e2e/` — интеграция с отдельным репозиторием сервера.
- `docs/PLUGIN.md` — основное руководство; `skills/obsi-plugin-docs/SKILL.md` и `AGENTS.md` — правило его обновления при изменении фич.
- `skills/obsi-plugin-testvault/` — повторяемая сборка и установка релизных файлов в локальный тестовый vault.

Заимствованные файлы синхронизации и условия лицензии указаны в `../NOTICE` и `../LICENSE-Apache-2.0.txt`.
