# Repository instructions

When adding or changing a user-facing feature, setting, workflow, command, or behavior of this plugin, follow [skills/obsi-plugin-docs/SKILL.md](skills/obsi-plugin-docs/SKILL.md) and update the relevant documentation in the same task. `docs/PLUGIN.md` is the canonical plugin guide; `README.md` is the quick start.

For a task with several substantial, independent parts, apply `$sol-delegate-luna` when that skill and Luna subagents are available. Delegate separable work with non-overlapping file scopes; keep integration, review, and final verification with the primary agent. Skip delegation for small or tightly coupled tasks.

When asked to compile or install the plugin into the local `testvault`, follow [skills/obsi-plugin-testvault/SKILL.md](skills/obsi-plugin-testvault/SKILL.md). Install only the release files and preserve the vault's `data.json`.
