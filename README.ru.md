# Sync and MCP

[English](README.md) | **Русский**

Плагин Obsidian синхронизирует vault'ы между устройствами со сквозным шифрованием и даёт ИИ-ассистентам (Claude и другим MCP-клиентам) доступ только к тем заметкам, которые вы выбрали. Работает с вашим собственным сервером [sync-and-mcp-backend](https://github.com/nejroseld/sync-and-mcp-backend).

## Возможности

- **Синхронизация со сквозным шифрованием.** Файлы шифруются на устройстве через rclone crypt ещё до отправки. Сервер хранит только шифротекст и не знает пароля шифрования.
- **Несколько vault'ов в одном.** Синхронизируйте всё хранилище или отдельные папки, у каждой свой серверный vault и свой пароль.
- **Любое число устройств.** Новое устройство подключается по QR-коду. У каждого свой токен, отключить можно любое отдельно.
- **Доступ ИИ через MCP.** Правила задают, какие заметки видит ассистент. Плагин публикует их на сервер, и Claude, ChatGPT или любой другой MCP-клиент может их читать и искать по ним.
- **Правки от ИИ.** Ассистент с правом записи предлагает изменения. Плагин применяет их локально, только если это разрешают правила и заметка не изменилась за это время. При конфликте ваши файлы не перезаписываются.
- **Аккаунты и приглашения.** Администратор сервера приглашает людей готовым сообщением, дальше каждый сам ведёт свои vault'ы, устройства и ассистентов.
- **Компьютер и телефон.** Работает на Windows, macOS, Linux, Android и iOS.

## Что видит сервер

У синхронизации и доступа ИИ разные правила конфиденциальности:

- синхронизируемые файлы попадают на сервер **зашифрованными**;
- заметки, открытые для ИИ, передаются на сервер **открытым текстом**: так сервер может строить по ним поиск и отдавать их MCP-клиентам.

Доступ ИИ по умолчанию выключен. Пока вы его не включите и не выберете заметки в правилах, ничего не публикуется.

## Что нужно

- Obsidian 1.4.0 или новее.
- Работающий сервер [sync-and-mcp-backend](https://github.com/nejroseld/sync-and-mcp-backend): свой или чужой, куда вас пригласил администратор.

## Установка

В каталоге Community plugins плагина пока нет, поэтому ставить его нужно одним из двух способов.

**Через BRAT (удобнее всего).** Установите [BRAT](https://github.com/TfTHacker/obsidian42-brat), выполните команду «BRAT: Add a beta plugin for testing» и введите `nejroseld/sync-and-mcp`. Обновления BRAT будет ставить сам.

**Вручную.** Скачайте `main.js`, `manifest.json` и `styles.css` из [последнего релиза](https://github.com/nejroseld/sync-and-mcp/releases/latest), положите их в `<vault>/.obsidian/plugins/sync-and-mcp/` и включите «Sync and MCP» в «Настройки» → «Сторонние плагины». При обновлении заменяйте только эти три файла и не трогайте `data.json`: в нём лежат локальные настройки и секреты.

## Первый запуск

При первом запуске откроется пошаговый мастер:

1. Выберите способ подключения:
   - «У меня есть приглашение»: вставьте сообщение от администратора целиком, мастер сам найдёт адрес сервера и код;
   - «Войти в мой аккаунт»;
   - «Перенести настройку с другого устройства»: отсканируйте QR-код с уже настроенного устройства.
2. Выберите серверный vault или создайте новый. Новому аккаунту мастер сразу предложит создать первый.
3. Задайте пароль шифрования. Он не совпадает с паролем аккаунта и должен быть одинаковым на всех устройствах.
4. Решите, будет ли у ИИ-ассистентов доступ к этому vault'у.

Когда мастер закончит, первая синхронизация запустится сама.

Настройки разделены на вкладки «Обзор», «Синхронизация», «Папки», «Устройства», «ИИ» и «Сервер». Состояние синхронизации видно в строке статуса, по щелчку открывается меню быстрых действий.

## Подключение ИИ-ассистента

Откройте «Настройки» → Sync and MCP → «ИИ» → «Ассистенты» и нажмите «Подключить ассистента». Укажите название, отметьте vault'ы и выберите доступ: «Читать и искать» или «Читать, искать и предлагать правки». Плагин покажет готовую команду для Claude Code, конфигурацию для Claude Desktop и адрес `…/mcp` с заголовком для любого другого MCP-клиента. Ключ доступа показывается один раз, кнопка «Отключить» его отзывает.

## Сборка из исходников

```bash
npm install
npm run typecheck
npm test
npm run build
```

Сборка создаёт `main.js` в корне репозитория. Чтобы выпустить релиз, укажите одну и ту же версию в `manifest.json`, `package.json` и `versions.json` и отправьте тег, равный версии (например `0.1.0`, без `v`). Workflow на GitHub соберёт плагин и создаст черновик релиза с `main.js`, `manifest.json` и `styles.css`.
